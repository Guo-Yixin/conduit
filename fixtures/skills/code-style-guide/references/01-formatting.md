# Formatting

- Two-space indentation, no tabs.
- Line length target: 100 columns, hard wrap at 120.
- One statement per line; no semicolon-chained statements.
- Trailing commas in multi-line literals.
- Braces on the same line as the opening statement (`if (x) {`), never on their own line.
- Blank line between logical blocks within a function, not between every statement.
