# Naming

- `camelCase` for variables and functions, `PascalCase` for types and classes.
- Booleans read as predicates: `isReady`, `hasChildren`, `canRetry` — never bare nouns.
- No Hungarian notation, no type suffixes (`userList` not `userArr`).
- Acronyms stay uppercase in types (`HTTPClient`), lowercase-led in variables (`httpClient`).
- Prefer full words over abbreviations except for well-known ones (`id`, `url`, `db`).
